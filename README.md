## How to use

Open `discover-lebanon-b05.html` in any browser — no server needed for local use.

For production, upload the HTML file and the `img/` folder to your web server or GitHub Pages.

---

## Design

- Mobile-first, optimised for smartphones
- Sticky dark green navigation bar
- Name and price on the same line for every dish
- Full-width photos using `<img>` tags (Experiences) or CSS background (all other cards)
- Gold (`#C8A84A`) prices for visual hierarchy
- No external dependencies except Google Fonts (Public Sans)
